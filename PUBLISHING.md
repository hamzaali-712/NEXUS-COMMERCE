# Publish this assignment pack as a GitHub repository

The files in this ZIP are a **ready-to-publish organizer documentation pack**. They do **not** create a remote GitHub repository by themselves, and they do not contain an implementation of the student's e-commerce app.

## Suggested repository title
`beyond-prompting-capstone-assignment-2026`

## Easiest method
1. Sign in to GitHub and open **New repository**.
2. Choose the correct personal account or organization, and name the repo `beyond-prompting-capstone-assignment-2026`.
3. Choose **Public** if students must access the instructions without collaborator invites.
4. Create the repository **without auto-generating a README**, as the pack already includes one.
5. Extract the ZIP locally and open a terminal in the extracted folder.
6. Run the following commands, replacing `OWNER` with the account/organization that actually owns the repository:

```bash
git init
git add .
git commit -m "Add Beyond Prompting capstone assignment brief"
git branch -M main
git remote add origin https://github.com/OWNER/beyond-prompting-capstone-assignment-2026.git
git push -u origin main
```

If Git identity, authentication, branch rules or permissions block a push, follow the error rather than assuming success. Do not push to the bootcamp learning repo unless you have explicit write permission. This package contains an organizer draft; confirm the proposed rubric and branding with GDGoC CUI Wah before public circulation.

## Student submissions
Students must create **their own, separate project repositories** with actual working code, prompt documentation and deployment evidence. They should submit those links through the form organizers share on 20 November 2026.
